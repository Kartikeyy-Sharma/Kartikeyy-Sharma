### 🧑‍💻 About Me

- 🎓 BCA @ Christ University, Delhi NCR
- 🔍 I don't just wire up APIs to an LLM — I design retrieval pipelines, chunking strategies, and evaluation loops that make AI systems actually *work* in production.
